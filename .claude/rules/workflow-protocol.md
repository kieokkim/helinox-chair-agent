## 작업 프로토콜

모든 비자명한 작업은 다음 순서를 따른다. 단계를 건너뛰지 않는다.

1. research → `docs/research_{작업명}.md` 작성. 코드 작성 금지.
2. 사용자 검토 및 인라인 메모
3. plan → `docs/plan_{작업명}.md` 작성. 코드 작성 금지.
4. 사용자 메모 → 반영 → 반복 (사용자가 만족할 때까지)
5. 구현. 단계 완료 시 plan 문서에 완료 표시.

## 계획 문서는 자체 .md 파일로 작성한다
내장 plan mode를 쓰지 않는다. docs/ 아래 실제 파일로 남긴다.

## 구현 명령 시 표준 조건
구현 단계에서는 다음이 항상 적용된다:
- 작업/단계 완료 시 plan 문서에 완료로 표시
- 모든 단계가 끝날 때까지 멈추지 않는다
- 타입 힌트를 생략하거나 Any로 채우지 않는다
- 수정할 때마다 기존 테스트를 실행해 새 문제를 만들지 않는다

## 방향이 틀렸을 때

패치로 고치지 않는다. `git reset` 또는 `git revert`로 되돌리고 범위를 좁혀
다시 시작한다.
